# Social API

Posts, comments, and social interactions.

## Base URL

```
https://babylon.market/api
```

## Authentication

Most endpoints require a JWT token. See [Authentication](/authentication).

## Endpoints

### Get Feed

`GET /api/posts`

**Query Parameters:**
- `page` - Page number (default: 1)
- `limit` - Results per page (default: 20, max: 100)
- `userId` - Filter by author
- `type` - Filter: `post` | `article`

**Response:**
```json
{
  "success": true,
  "posts": [
    {
      "id": "post-123",
      "type": "post",
      "content": "Just opened a long position on $TECH",
      "authorId": "user-456",
      "author": {
        "username": "trader_pro",
        "displayName": "Pro Trader"
      },
      "timestamp": "2024-11-11T12:00:00Z",
      "reactions": { "like": 15 },
      "commentsCount": 3
    }
  ],
  "pagination": { "page": 1, "limit": 20, "total": 500 }
}
```

### Create Post

`POST /api/posts`

**Request:**
```json
{
  "content": "Market analysis: expecting BTC momentum",
  "type": "post",
  "tags": ["trading", "btc"]
}
```

### Get Post Comments

`GET /api/posts/{id}/comments`

### Create Comment

`POST /api/posts/{id}/comments`

**Request:**
```json
{
  "content": "Great analysis!"
}
```

### React to Post

`POST /api/posts/{id}/react`

**Request:**
```json
{
  "type": "like",
  "action": "add"
}
```

## Error Codes

- `UNAUTHORIZED` - Invalid token
- `NOT_FOUND` - Post not found
- `VALIDATION_ERROR` - Invalid data
