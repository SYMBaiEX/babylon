# Python RL Training

> **⚠️ Experimental** - Under active development. See `packages/training/README.md` for full documentation.

RL training for Babylon agents using trajectory-based learning with MLX, CUDA, or Tinker cloud.

## Quick Start

### 1. Generate Trajectories

```bash
bun run dev  # Start server
babylon train parallel --archetypes trader --num-agents 5 --ticks 20
```

### 2. Train

```bash
cd packages/training/python
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt

python scripts/train_local.py  # Auto-detects MLX/CUDA/CPU
```

## Hardware

| Platform | Backend | Model |
|----------|---------|-------|
| Mac M1/M2 (16GB) | MLX | `mlx-community/Qwen2.5-1.5B-Instruct-4bit` |
| GTX 3060+ | CUDA | `Qwen/Qwen2.5-1.5B-Instruct` |
| Any | Tinker | Cloud-based |

## Environment

```bash
DATABASE_URL=postgresql://...   # Required
OPENAI_API_KEY=sk-...           # For RLAIF judge
TINKER_API_KEY=...              # For cloud training
```

## How It Works

1. Agents generate trajectories via `babylon train parallel`
2. LLM judge scores trajectories using RLAIF
3. Trainer optimizes model (MLX/CUDA/Tinker)
4. Updated model deployed
