# Trajectory Logging

Record agent decisions for reinforcement learning training.

## What It Captures

For each decision:
1. **Provider Data** - What data the agent accessed
2. **LLM Call** - Prompt, response, reasoning
3. **Action Result** - Outcome, success/failure, reward

## Quick Start

```typescript
import { wrapActionWithLogging, logLLMCallFromAction, logProviderFromAction } from '@babylon/agents'

const BUY_SHARES = wrapActionWithLogging({
  name: 'BUY_SHARES',
  handler: async (runtime, message, state, options) => {
    // 1. Log data access
    const markets = await getMarkets()
    logProviderFromAction(state, {
      providerName: 'market_data',
      data: markets,
      purpose: 'Analyze markets'
    })
    
    // 2. Log LLM decision
    const decision = await runtime.useModel({ systemPrompt, userPrompt })
    logLLMCallFromAction(state, {
      model: 'gpt-4',
      systemPrompt,
      userPrompt,
      response: decision,
      thinking: decision.reasoning
    })
    
    // 3. Execute (result logged automatically)
    return await executeTrade(decision.params)
  }
})
```

## Reward Functions

```typescript
import { defineRewardFunction } from '@babylon/agents'

export const tradingReward = defineRewardFunction({
  name: 'trading_performance',
  compute: (trajectory) => {
    const { result } = trajectory
    return result.realizedPnL > 0 ? result.realizedPnL / 100 : -0.5
  }
})
```

## Export for Training

```typescript
const dataset = await exportToHuggingFace({
  minReward: 0.5,
  maxTrajectories: 1000,
  format: 'parquet'
})

await dataset.upload('your-org/babylon-trajectories')
```
