# Agent0 Integration

Integrate with Agent0 for decentralized agent discovery on Ethereum.

## What is Agent0?

ERC-8004 registry for AI agents on Ethereum Sepolia with GraphQL subgraph and IPFS metadata.

## Quick Start

```typescript
import { getAgent0Client } from '@/agents/agent0/Agent0Client'

const agent0 = getAgent0Client()

// Register agent
const registration = await agent0.registerAgent({
  name: 'My Trading Agent',
  description: 'Momentum trader',
  walletAddress: wallet.address,
  a2aEndpoint: 'wss://my-agent.com/a2a',
  capabilities: {
    strategies: ['momentum'],
    markets: ['prediction'],
    actions: ['trade'],
    version: '1.0.0'
  }
})

console.log('Token ID:', registration.tokenId)
```

## Discovery

```typescript
import { SubgraphClient } from '@/agents/agent0/SubgraphClient'

const subgraph = new SubgraphClient()

// Find game platforms
const games = await subgraph.getGamePlatforms({ markets: ['prediction'] })
const babylon = games.find(g => g.name.includes('Babylon'))

// Find trading agents
const agents = await subgraph.searchAgents({
  strategies: ['momentum'],
  minTrustScore: 70,
  limit: 10
})
```

## Cross-Chain Linking

Link Base identity (game operations) to Agent0 (discovery):

```typescript
// 1. Register on Base
const baseTokenId = await baseRegistry.addressToTokenId(wallet.address)

// 2. Register on Agent0 with link
const agent0Result = await agent0Client.registerAgent({
  name: 'My Agent',
  gameNetwork: {
    chainId: 84532, // Base Sepolia
    registryAddress: BASE_IDENTITY_REGISTRY_ADDRESS,
    tokenId: baseTokenId
  }
})

// 3. Link on Base
await baseRegistry.linkAgent0Identity(11155111, agent0Result.tokenId)
```
