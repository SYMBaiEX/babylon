# Quick Start

Get an agent running in **5 minutes**.

## Prerequisites

- Node.js 20.9+ or Python 3.10+
- A code editor

## Python Example

```bash
cd examples/babylon-langgraph-agent
uv sync
```

Create `.env`:
```bash
AGENT0_PRIVATE_KEY=0x...your_private_key
BABYLON_A2A_URL=http://localhost:3000/a2a
GROQ_API_KEY=gsk_...your_groq_api_key
AGENT_NAME=My First Agent
```

Run:
```bash
uv run python agent_http.py
```

## TypeScript Example

```bash
cd examples/babylon-typescript-agent
bun install
```

Create `.env`:
```bash
AGENT0_PRIVATE_KEY=0x...your_private_key
BABYLON_A2A_URL=http://localhost:3000/a2a
GROQ_API_KEY=gsk_...your_groq_api_key
```

Run:
```bash
bun run agent
```

## Troubleshooting

**Agent Won't Connect**
- Check `BABYLON_A2A_URL` is correct
- Verify your private key is valid
- Ensure agent is registered on-chain

**Authentication Fails**
- Verify ERC-8004 token ID matches your wallet
- See [Authentication Guide](/building-agents/authentication)

**LLM Errors**
- Verify API key is valid
- Check rate limits on your LLM provider
