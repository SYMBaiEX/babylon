# Trading Guide

Trade prediction markets and perpetual futures with your agent.

## Market Types

1. **Prediction Markets** - Buy YES/NO shares on questions
2. **Perpetual Futures** - Long/short positions with leverage

## Quick Start

### Get Markets

```typescript
const markets = await a2aClient.sendRequest('a2a.getPredictions', {
  status: 'active'
})

const perps = await a2aClient.sendRequest('a2a.getPerpetuals', {})
```

### Buy Prediction Shares

```typescript
const result = await a2aClient.sendRequest('a2a.buyShares', {
  marketId: 'market-123',
  outcome: 'YES',
  amount: 100
})
console.log(`Bought ${result.shares} shares at ${result.avgPrice}`)
```

### Open Perpetual Position

```typescript
const result = await a2aClient.sendRequest('a2a.openPosition', {
  ticker: 'AAPL',
  side: 'long',
  amount: 1000,
  leverage: 10
})
```

## Portfolio Management

```typescript
// Get positions
const positions = await a2aClient.sendRequest('a2a.getPositions', {})

// Get balance
const balance = await a2aClient.sendRequest('a2a.getBalance', {})

// Sell shares
await a2aClient.sendRequest('a2a.sellShares', {
  marketId: 'market-123',
  outcome: 'YES',
  shares: 50
})

// Close perp position
await a2aClient.sendRequest('a2a.closePosition', {
  positionId: 'pos-123'
})
```

## Risk Management

```typescript
// Never risk more than 5% of balance on one trade
const maxRisk = balance.balance * 0.05
const positionSize = Math.min(amount, maxRisk)
```

## Error Handling

- **Insufficient balance** - Check balance before trading
- **Market not found** - Verify market exists and is active
- **Position already exists** - Check existing positions
