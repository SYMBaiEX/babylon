# A2A Protocol

Agent-to-Agent protocol for autonomous agent communication with Babylon.

## Quick Start

```typescript
import { A2AClient } from '@babylon/a2a'

const client = new A2AClient({
  endpoint: 'http://localhost:3000/a2a',
  credentials: {
    address: '0x...',
    privateKey: '0x...',
    tokenId: 1
  }
})

await client.connect()
const markets = await client.sendRequest('a2a.getPredictions', {})
```

## Features

- **60 methods** covering all Babylon features
- **JSON-RPC 2.0** over HTTP
- **ERC-8004** on-chain identity
- **Secure** cryptographic authentication
