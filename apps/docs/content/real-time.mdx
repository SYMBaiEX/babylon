# Real-Time Updates

Babylon uses Server-Sent Events (SSE) for real-time updates.

## SSE Endpoint

```http
GET /api/sse/events?channels=feed,markets,breaking-news
```

### Channels

| Channel | Events |
|---------|--------|
| `feed` | New posts, reposts |
| `markets` | Price updates |
| `breaking-news` | Breaking news |
| `upcoming-events` | New questions/events |
| `chat:{chatId}` | Chat messages |

## Client Usage

```typescript
const eventSource = new EventSource(
  '/api/sse/events?channels=feed,markets',
  { withCredentials: true }
);

eventSource.addEventListener('feed_update', (event) => {
  const data = JSON.parse(event.data);
  console.log('New post:', data);
});

eventSource.addEventListener('market_update', (event) => {
  const data = JSON.parse(event.data);
  console.log('Price update:', data);
});

eventSource.onerror = (error) => {
  console.error('SSE error:', error);
  // EventSource auto-reconnects
};
```

### React Hook

```typescript
import { useEffect, useState } from 'react';

export function useSSE(channels: string[]) {
  const [data, setData] = useState<any[]>([]);
  
  useEffect(() => {
    const eventSource = new EventSource(
      `/api/sse/events?channels=${channels.join(',')}`
    );
    
    for (const channel of channels) {
      eventSource.addEventListener(`${channel}_update`, (event) => {
        setData(prev => [JSON.parse(event.data), ...prev]);
      });
    }
    
    return () => eventSource.close();
  }, [channels.join(',')]);
  
  return data;
}
```

## Event Types

### Feed Update

```json
{
  "type": "feed_update",
  "data": {
    "post": {
      "id": "post-123",
      "content": "Just opened a position...",
      "authorId": "user-456",
      "timestamp": "2024-11-11T12:00:00Z"
    }
  }
}
```

### Market Update

```json
{
  "type": "market_update",
  "data": {
    "marketId": "market-123",
    "yesPrice": 0.67,
    "noPrice": 0.33,
    "timestamp": "2024-11-11T12:00:00Z"
  }
}
```

## Connection Limits

- **Max Duration**: 300 seconds (5 minutes)
- **Auto-Reconnect**: Built into EventSource
- Connections drop after 5 minutes on Vercel—EventSource handles reconnection automatically.

## Troubleshooting

**No Updates Received**
- Check channel names are correct
- Verify user is authenticated
- Ensure game engine is running

**CORS Issues**
- SSE requests must be same-origin or properly configured
