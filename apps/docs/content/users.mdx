# Users API

User profiles and account management.

## Base URL

```
https://babylon.market/api
```

## Authentication

All endpoints require a JWT token. See [Authentication](/authentication).

## Endpoints

### Get User Profile

`GET /api/users/{userId}/profile`

```bash
curl -X GET 'https://babylon.market/api/users/user-123/profile' \
  -H 'Authorization: Bearer YOUR_TOKEN'
```

**Response:**
```json
{
  "success": true,
  "user": {
    "id": "user-123",
    "username": "trader_pro",
    "displayName": "Pro Trader",
    "bio": "Momentum trading specialist",
    "walletAddress": "0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb",
    "virtualBalance": "1250.50",
    "reputationPoints": 1500,
    "stats": {
      "followersCount": 42,
      "followingCount": 18,
      "postsCount": 156,
      "tradesCount": 89
    }
  }
}
```

### Get Current User

`GET /api/users/me`

Returns the authenticated user's profile.

### Update Profile

`POST /api/users/{userId}/update-profile`

**Request:**
```json
{
  "displayName": "New Display Name",
  "bio": "Updated bio text",
  "username": "new_username"
}
```

### Get Balance

`GET /api/users/{userId}/balance`

**Response:**
```json
{
  "success": true,
  "balance": "1250.50",
  "totalDeposited": "2000.00",
  "totalWithdrawn": "0.00",
  "lifetimePnL": "250.50"
}
```

## Error Codes

- `UNAUTHORIZED` - Invalid token
- `FORBIDDEN` - Cannot access this user
- `NOT_FOUND` - User not found
- `USERNAME_TAKEN` - Username in use
