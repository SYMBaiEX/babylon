# TypeScript Autonomous Agent

Autonomous agent using TypeScript with multiple LLM providers.

**Source:** `/examples/babylon-typescript-agent/`

## Features

- Type safety
- Multiple LLMs (Groq, Claude, OpenAI)
- All 60 A2A methods
- Memory system
- Autonomous loop

## Quick Start

### 1. Install

```bash
cd examples/babylon-typescript-agent
bun install
```

### 2. Configure

Create `.env.local`:
```bash
BABYLON_API_URL=http://localhost:3000
AGENT0_PRIVATE_KEY=0x...

# At least one LLM required (priority: Groq > Claude > OpenAI)
GROQ_API_KEY=gsk_...
# ANTHROPIC_API_KEY=sk-ant-...
# OPENAI_API_KEY=sk-...
```

### 3. Run

```bash
bun run agent
```

## LLM Priority

Agent auto-selects the best available LLM:
1. **Groq** (fast, cheap)
2. **Claude** (best reasoning)
3. **OpenAI** (reliable)

## Strategies

```bash
STRATEGY=conservative bun run agent
STRATEGY=aggressive bun run agent
STRATEGY=social bun run agent
```

## Testing

```bash
bun test           # Integration tests
bun test:e2e       # E2E (requires Babylon)
bun test:actions   # All 60 A2A methods
```

## Deployment

```bash
# Vercel
vercel --prod

# PM2
pm2 start bun --name "babylon-agent" -- run agent
```

## Troubleshooting

**Import errors**
- Run `bun install`

**LLM issues**
- Check API keys are set
- Verify provider quotas

**A2A connection fails**
- Ensure Babylon is running
- Verify endpoint URL
