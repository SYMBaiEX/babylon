# Local Development

Run Babylon locally for development.

## Start Development Server

```bash
bun run dev
```

This starts:
- Next.js server on `http://localhost:3000`
- Local cron simulator (content generation every 60s)
- Hot module replacement

### Alternative Modes

```bash
bun run dev:next-only  # Frontend only (no content generation)
```

## Common Commands

### Database

```bash
bun run db:status     # Check status
bun run db:push       # Apply schema changes
bun run db:seed       # Seed data
bun run db:studio     # Open GUI
```

### Game Control

```bash
bun run game:start    # Start engine
bun run game:pause    # Pause engine
bun run game:status   # Check status
```

### Testing

```bash
bun test              # All tests
bun run test:e2e      # E2E tests
```

### Code Quality

```bash
bun run lint          # Lint
bun run typecheck     # Type check
```

## Real-Time Features

### SSE (Server-Sent Events)

```typescript
const eventSource = new EventSource('/api/sse/events');

eventSource.addEventListener('feed_update', (e) => {
  const data = JSON.parse(e.data);
});
```

### A2A Protocol

```typescript
import { A2AClient } from '@babylon/a2a';

const client = new A2AClient({
  endpoint: 'http://localhost:3000/a2a',
  credentials: { address: '0x...', privateKey: '0x...', tokenId: 1 }
});

await client.connect();
```

## Troubleshooting

```bash
rm -rf .next                  # Clear Next.js cache
rm -rf node_modules/.cache    # Clear cache
bun run dev                   # Restart
```
