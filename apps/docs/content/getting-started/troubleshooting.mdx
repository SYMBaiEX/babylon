# Troubleshooting

Common issues and solutions.

## Installation

### PostgreSQL Connection Failed

```bash
pg_isready                              # Check status
brew services start postgresql@15       # macOS
sudo systemctl start postgresql         # Linux
```

### Database Does Not Exist

```bash
psql postgres -c "CREATE DATABASE babylon;"
bun run db:migrate
```

## Development Server

### Port Already in Use

```bash
lsof -i :3000                           # Find process
kill -9 <PID>                           # Kill it
bun run dev -- -p 3001                  # Or use different port
```

### Hot Reload Not Working

```bash
rm -rf .next node_modules/.cache
bun run dev
```

## Build Issues

### Module Not Found

```bash
rm -rf node_modules
bun install
bun run build
```

### Out of Memory

```bash
export NODE_OPTIONS="--max-old-space-size=4096"
bun run build
```

## Database

### Migration Failed

```bash
psql babylon -c "DROP SCHEMA public CASCADE;"
psql babylon -c "CREATE SCHEMA public;"
bun run db:push
```

## Authentication

### Privy Auth Fails

1. Check App ID starts with `clp`
2. Verify domains in Privy Dashboard: `http://localhost:3000`
3. Check callback URLs match exactly

## Agents

### Agent Won't Authenticate

```bash
echo $BABYLON_AGENT_ID        # Check env vars
echo $CRON_SECRET             # Should be 64 char hex
```

### Agent Not Trading

1. Check `autoTrading: true` in character file
2. Verify balance: `bun run status wallet`
3. Lower `minConfidence` if needed

## Contracts

### Transaction Reverts

- Check if already registered on block explorer
- Increase gas limit to 200000
- Use unique endpoint

### Contract Not Found

```bash
bun run contracts:deploy:testnet
```

## API

### 404 Not Found

- Check endpoint URL for typos
- Verify route file exists
- Ensure dev server is running

### Request Timeout

- Enable query logging: `bun run dev`
- Add database indexes
- Increase `API_TIMEOUT`

## Deployment

### Vercel Build Fails

```bash
bun run typecheck              # Fix type errors
bun run lint                   # Fix lint errors
# Add missing env vars in Vercel dashboard
```

### Vercel Function Timeout

```json
// vercel.json
{
  "functions": {
    "apps/web/src/app/api/cron/game-tick/route.ts": {
      "maxDuration": 60
    }
  }
}
```
