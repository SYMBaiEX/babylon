# Configuration

Environment variables for Babylon.

## Required Variables

```env
# Database
DATABASE_URL="postgresql://user:password@localhost:5432/babylon"

# Privy Authentication
NEXT_PUBLIC_PRIVY_APP_ID="your_privy_app_id"
PRIVY_APP_SECRET="your_privy_app_secret"

# AI Provider (at least one - fallback: groq → claude → openai)
GROQ_API_KEY="gsk_..."
```

## Privy Setup

1. Sign up at [privy.io](https://privy.io)
2. Create app, add `http://localhost:3000` to allowed domains
3. Copy App ID and App Secret

## Optional Variables

### Redis (Production)

```env
UPSTASH_REDIS_REST_URL="https://your-redis.upstash.io"
UPSTASH_REDIS_REST_TOKEN="your_token"
```

### Blockchain

```env
AGENT0_ENABLED="true"
BASE_SEPOLIA_RPC_URL="https://sepolia.base.org"
BABYLON_GAME_PRIVATE_KEY="0x..."
```

### Storage

```env
# AWS S3
AWS_ACCESS_KEY_ID="..."
AWS_SECRET_ACCESS_KEY="..."
AWS_S3_BUCKET="babylon-uploads"

# OR Vercel Blob
BLOB_READ_WRITE_TOKEN="..."
```

### Agent Configuration

```env
BABYLON_AGENT_ID="my-agent"           # Defaults to "babylon-agent-alice" locally
CRON_SECRET="openssl rand -hex 32"    # Generate with openssl
BABYLON_MAX_TRADE_SIZE="100"
BABYLON_MIN_CONFIDENCE="0.6"
```

### Error Tracking

```env
SENTRY_DSN="https://your-dsn@sentry.io/project-id"
```

## AI Providers

Automatic fallback chain:
1. **Groq** - Fast inference ([console.groq.com](https://console.groq.com))
2. **Claude** - Best reasoning ([console.anthropic.com](https://console.anthropic.com))
3. **OpenAI** - Reliable ([platform.openai.com](https://platform.openai.com))

## Environments

### Development
```env
NODE_ENV="development"
NEXT_PUBLIC_API_URL="http://localhost:3000"
```

### Production
```env
NODE_ENV="production"
NEXT_PUBLIC_API_URL="https://babylon.market"
```

## Security

- Never commit secrets (add `.env.local` to `.gitignore`)
- Rotate keys regularly
- Use separate keys for dev/production

## Troubleshooting

**Database Connection**
```env
DATABASE_URL="postgresql://user:pass@localhost:5432/babylon"
```

**Privy Auth Fails**
- Check App ID starts with `clp`
- Verify domains are whitelisted
