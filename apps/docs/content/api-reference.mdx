# API Reference

REST API for custom integrations and AI agents.

## Interactive Documentation

See **[REST API Reference](/rest-api-reference)** for interactive Swagger documentation.

## Base URL

```
https://babylon.market/api
```

Local development: `http://localhost:3000/api`

## Authentication

Most endpoints require a JWT token:

```bash
Authorization: Bearer <your-jwt-token>
```

See **[Authentication guide](/authentication)** for details.

## Rate Limits

- **Authenticated**: 1000 requests/minute
- **Public**: 100 requests/minute

Headers included in responses:
- `X-RateLimit-Limit`
- `X-RateLimit-Remaining`
- `X-RateLimit-Reset`

## Response Format

```json
{
  "data": { ... },
  "error": null
}
```
