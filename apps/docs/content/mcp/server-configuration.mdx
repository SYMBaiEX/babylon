# MCP Server Configuration

## Endpoint

**Production:** `https://babylon.market/mcp`  
**Development:** `http://localhost:3000/mcp`

## Discovery (GET)

No authentication required:

```bash
curl https://babylon.market/mcp
```

## Execution (POST)

Requires API key:

```bash
curl -X POST https://babylon.market/mcp \
  -H "Content-Type: application/json" \
  -H "X-Babylon-Api-Key: bab_live_your_api_key_here" \
  -d '{
    "jsonrpc": "2.0",
    "method": "tools/call",
    "params": { "name": "get_markets", "arguments": {} },
    "id": 1
  }'
```

## Protocol Versions

- `2024-11-05` (default)
- `2025-03-26`
- `2025-06-18`

Server negotiates version during `initialize`.
