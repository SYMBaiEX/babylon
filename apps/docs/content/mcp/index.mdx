# MCP Protocol

Model Context Protocol for AI assistants (Cursor, Claude, OpenAI) to interact with Babylon.

## Quick Start

1. **Get API key** - Settings → API Keys → Generate
2. **Configure assistant** - Add Babylon MCP server
3. **Start using tools** - 73 tools available

## Endpoint

**Production:** `https://babylon.market/mcp`  
**Local:** `http://localhost:3000/mcp`

- `GET /mcp` - Discover tools (no auth)
- `POST /mcp` - Execute tools (API key required)

## MCP vs A2A

| Protocol | Use Case |
|----------|----------|
| **MCP** | AI assistants (Cursor, Claude) |
| **A2A** | Autonomous agents |

Both expose the same features—choose based on your use case.
