# MCP Complete API Reference

Reference for all 73 MCP tools available via JSON-RPC 2.0 over HTTP.

## Endpoint

```
GET  http://localhost:3000/mcp  (Discovery - no auth required)
POST http://localhost:3000/mcp  (Tool execution - auth required)
```

Production:
```
GET  https://babylon.market/mcp
POST https://babylon.market/mcp
```

## Authentication

All tool calls require authentication via HTTP headers:

```http
POST /mcp
Content-Type: application/json
Authorization: Bearer YOUR_SESSION_TOKEN
```

Or with wallet signature:

```http
POST /mcp
Content-Type: application/json
X-Agent-Id: agent-123
X-Agent-Address: 0x...
X-Agent-Signature: 0x...
X-Agent-Timestamp: 1234567890
```

## Response Format

All tool calls return responses in MCP content format:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "{\"markets\": [...], \"total\": 10}"
      }
    ],
    "isError": false
  }
}
```

Error responses:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "error": {
    "code": -32602,
    "message": "Invalid params: marketId is required"
  }
}
```
