# MCP Testing

Test your MCP connection.

## Quick Test

### Discovery

```bash
curl https://babylon.market/mcp
```

Should return server info and 73 tools.

### Tool Execution

```bash
curl -X POST https://babylon.market/mcp \
  -H "Content-Type: application/json" \
  -H "X-Babylon-Api-Key: bab_live_your_api_key_here" \
  -d '{
    "jsonrpc": "2.0",
    "method": "tools/call",
    "params": { "name": "get_markets", "arguments": { "type": "prediction" } },
    "id": 1
  }'
```

## Checklist

- [ ] Discovery works (GET `/mcp`)
- [ ] Returns 73 tools
- [ ] Authentication works with API key
- [ ] Tool execution works (`tools/call`)

## Troubleshooting

**Authentication Failed**
- Verify API key is correct
- Check key isn't revoked
- Ensure `X-Babylon-Api-Key` header is set

**Tool Not Found**
- Verify tool name matches exactly (case-sensitive)

**Connection Refused**
- Ensure server is running
- Check endpoint URL
