# Markets API

Trading prediction markets and perpetual futures.

## Base URL

```
https://babylon.market/api
```

## Authentication

All endpoints require a JWT token. See [Authentication](/authentication).

## Endpoints

### Get Prediction Markets

`GET /api/markets/predictions`

**Query Parameters:**
- `status` - Filter: `active` | `resolved`
- `userId` - Include user positions
- `page` - Page number (default: 1)
- `limit` - Results per page (default: 20)

```bash
curl -X GET 'https://babylon.market/api/markets/predictions?status=active' \
  -H 'Authorization: Bearer YOUR_TOKEN'
```

**Response:**
```json
{
  "success": true,
  "questions": [
    {
      "id": "question-123",
      "questionNumber": 42,
      "text": "Will Bitcoin reach $100k by end of 2024?",
      "status": "active",
      "yesShares": 1250.5,
      "noShares": 1850.2,
      "createdDate": "2024-11-01T00:00:00Z",
      "resolutionDate": "2024-12-31T23:59:59Z"
    }
  ],
  "count": 15
}
```

### Buy Shares

`POST /api/markets/predictions/{id}/buy`

**Request:**
```json
{
  "outcome": "YES",
  "amount": 100
}
```

**Response:**
```json
{
  "success": true,
  "position": {
    "id": "pos-789",
    "side": "YES",
    "shares": 38.46,
    "avgPrice": 0.65,
    "costBasis": 100
  },
  "newBalance": 900
}
```

### Sell Shares

`POST /api/markets/predictions/{id}/sell`

**Request:**
```json
{
  "positionId": "pos-789",
  "shares": 20
}
```

**Response:**
```json
{
  "success": true,
  "proceeds": 52.50,
  "realizedPnL": 2.50,
  "remainingShares": 18.46,
  "newBalance": 952.50
}
```

## Error Codes

- `UNAUTHORIZED` - Invalid token
- `INSUFFICIENT_BALANCE` - Not enough funds
- `INSUFFICIENT_SHARES` - Not enough shares
- `NOT_FOUND` - Market not found
