# HuggingFace Dataset Integration

**Status**: Production Ready - Dataset Live ✅  
**Dataset**: https://huggingface.co/datasets/elizaos/babylon-game-data

---

## Overview

Babylon automatically publishes training data to HuggingFace daily via GitHub Actions.

**What's Published**:
- Agent trajectories (decisions + environment + ground truth)
- Benchmark scenarios (complete game states)
- Model performance results

**Frequency**: Daily at 2 AM UTC  
**Organization**: elizaos  
**Dataset**: babylon-game-data

---

## Dataset Structure

```
elizaos/babylon-game-data/
├── README.md                   - Dataset card
├── index.json                  - Metadata
├── summary.json                - Statistics
├── trajectories.jsonl          - Agent trajectories (JSONL format)
├── benchmarks-metadata.json    - Benchmark file list
└── monthly-data/
    ├── 2025-10.json           - October aggregated data
    ├── 2025-11.json           - November aggregated data
    └── YYYY-MM.json           - Each month's data
```

## Using the Dataset

### Download

```bash
# Install HuggingFace CLI
pip install huggingface_hub

# Download dataset
huggingface-cli download elizaos/babylon-game-data
```

### Load in Python

```python
from datasets import load_dataset

# Load dataset
dataset = load_dataset("elizaos/babylon-game-data")

# Access trajectories
trajectories = dataset['train']

# Use for training
for trajectory in trajectories:
    agent_id = trajectory['agentId']
    steps = trajectory['steps']
    reward = trajectory['totalReward']
    # Train your model
```

## GitHub Actions (Automatic)

### Setup

**1. Add GitHub Secrets:**

Go to: `https://github.com/YOUR_ORG/babylon/settings/secrets/actions`

Add:
```
HUGGING_FACE_TOKEN = your_token_here
DATABASE_URL = your_postgres_url
```

**2. Push to GitHub**

The workflow is already configured at `.github/workflows/daily-dataset-upload.yml`

**3. Monitor**

Check the Actions tab after 2 AM UTC each day.

### Workflow Configuration

```yaml
# Runs daily at 2 AM UTC
schedule:
  - cron: '0 2 * * *'

# What it does:
1. Collect data from database (memory-safe batching)
2. Organize by month
3. Upload to elizaos/babylon-game-data
4. Verify upload
```

## Offline Simulation

Download the dataset and run agents offline (100-1000x faster than real-time):

```bash
# Download dataset
huggingface-cli download elizaos/babylon-game-data

# Run offline simulation
npx tsx scripts/run-offline-simulation.ts --month=2025-11 --agent=my-agent
```

**Benefits**:
- No API calls needed
- Faster-than-real-time
- Perfect for testing/development
- Deterministic replay

---

## Memory Safety

The data collection uses memory-safe practices to prevent OOM:

- **Batch Processing**: 100 items at a time
- **Hard Limits**: Max 1,000 trajectories, 500 benchmarks
- **JSONL Format**: Line-by-line streaming
- **Forced GC**: Release memory between batches

## Training with Dataset

### Use in Python Training

```python
# Download from HuggingFace
from datasets import load_dataset
dataset = load_dataset("elizaos/babylon-game-data")

# Use for GRPO training
from babylon_trainer import BabylonTrainer

trainer = BabylonTrainer(
    dataset="elizaos/babylon-game-data",
    base_model="Qwen/Qwen2.5-0.5B-Instruct"
)

# Train on trajectories
model = await trainer.train_window(window_id)
```
